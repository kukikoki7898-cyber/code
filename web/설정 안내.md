# 웹 버전(구글 로그인 방식) 준비 안내

웹 버전은 주소 하나를 모두가 함께 쓰는 방식입니다. 선생님마다 그 주소에서 구글로 로그인하면
기록은 **로그인한 사람의 구글 드라이브**에 저장됩니다. 서버가 없어서 운영하는 사람의 사용량 한도를 쓰지 않습니다.

이 문서는 **주소를 처음 여는 사람(운영자) 한 명만** 하면 되는 준비입니다. 약 30분 걸립니다.
다른 선생님들은 주소만 받으면 됩니다.

## 1. 구글 클라우드 프로젝트 만들기

1. <https://console.cloud.google.com> 에 접속해 로그인합니다.
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `1인1역` → **만들기**.

## 2. API 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**.
2. `Google Sheets API`를 검색해 **사용**을 누릅니다.
3. `Google Drive API`를 검색해 **사용**을 누릅니다.

## 3. 로그인 화면(OAuth 동의 화면) 만들기

1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (새 화면에서는 "Google 인증 플랫폼").
2. 앱 이름 `우리 반 1인 1역`, 지원 이메일은 본인 메일, 대상은 **외부**를 고르고 만듭니다.
3. **데이터 액세스(범위)** 에서 범위 추가를 눌러 아래 두 가지를 넣습니다.
   - `https://www.googleapis.com/auth/drive.file` (이 앱이 만든 파일만 보고 고치기)
   - `https://www.googleapis.com/auth/userinfo.email` (로그인한 메일 주소 보기)
4. **대상** 에서 **앱 게시**를 눌러 "프로덕션" 상태로 바꿉니다.

> "테스트" 상태로 두면 등록한 사람 100명까지만 쓸 수 있고 7일마다 다시 로그인해야 합니다. 반드시 게시해 주세요.
> 위 두 범위는 구글이 민감하지 않은 범위로 분류하므로 별도 심사 없이 게시할 수 있는 것으로 알고 있습니다.
> 게시 화면에서 심사가 필요하다고 나오면 그 문구를 알려 주세요.

## 4. 클라이언트 ID 만들기

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형 **웹 애플리케이션**.
3. **승인된 자바스크립트 원본**에 웹 주소의 앞부분을 넣습니다. GitHub Pages를 쓰면 `https://(깃허브 아이디).github.io` 입니다. (뒤에 `/` 나 폴더 이름을 붙이지 않습니다.)
4. **만들기**를 누르고 나온 **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사합니다. 비밀번호가 아니므로 공개되어도 됩니다. "클라이언트 보안 비밀"은 쓰지 않습니다.

## 5. 클라이언트 ID 넣기

`docs/config.js` 파일을 열어 따옴표 안에 붙여 넣습니다.

```js
window.ONE_ROLE_CONFIG = {
  clientId: '1234567890-abcdefg.apps.googleusercontent.com'
};
```

## 6. 웹에 올리기 (GitHub Pages)

1. 저장소가 **공개(Public)** 여야 합니다. (무료 계정 기준)
2. 이 브랜치를 기본 브랜치(`main`)에 합칩니다.
3. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs** 로 고르고 **Save**.
4. 1~2분 뒤 `https://(깃허브 아이디).github.io/(저장소 이름)/` 주소로 열립니다.

## 7. 확인하기

1. 주소를 열면 "구글 로그인이 필요해요" 창이 나옵니다. **구글로 로그인**을 누릅니다.
2. 권한 화면에서 허용합니다.
3. **새 학급 만들기** → 설정에서 친구 추가 → 이름표를 눌러 도장을 찍습니다.
4. 구글 드라이브에 "1인 1역 기록 - (학급 이름)" 파일이 생기고 `기록` 시트에 ○ 가 들어가면 성공입니다.

오류가 나면 화면 아래 검은 띠에 나오는 문구를 그대로 알려 주세요.

## 알아 둘 점

- **전자칠판은 로그인된 상태여야 합니다.** 교사 개인 계정 대신 칠판 전용 구글 계정을 만들어 쓰기를 권합니다. 기록 파일을 교사 개인 계정에 공유해 두면 자기 PC에서 볼 수 있습니다.
- 로그인은 약 1시간마다 갱신됩니다. 화면을 누를 때 작은 창이 잠깐 떴다 사라지면 정상입니다. 창이 막히면 "다시 로그인해 주세요" 안내가 나옵니다.
- 이 앱은 **자기가 만든 스프레드시트만** 볼 수 있습니다. 드라이브의 다른 파일은 볼 수 없습니다. 그래서 주소를 붙여 넣어 다른 시트로 바꾸는 기능은 웹 버전에 없고, "새 스프레드시트 만들어서 바꾸기"만 있습니다.
- 구글 시트 API에는 분당 요청 수 제한이 있습니다(프로젝트 전체 약 300건, 한 사람 약 60건). 수백 학급이 같은 시간에 몰리면 저장이 잠깐 밀릴 수 있으며, 화면의 도장은 남아 있다가 자동으로 다시 저장됩니다.
- 코드를 고친 뒤에는 `node tools/build-web.js` 로 `docs/index.html` 을 다시 만들어 올립니다.
