우리 반 1인 1역 개인정보처리방침

"우리 반 1인 1역"은 교실에서 학생의 1인 1역 수행을 기록하는 무료 웹앱입니다. 이 앱에는 운영자의 서버가 없으며, 사용자가 입력한 내용은 운영자에게 전송되거나 저장되지 않습니다.

1. 저장되는 정보와 위치

기본 저장 방식은 이 기기에 저장하기(로그인 없음)이며, 이때는 아래 정보가 모두 사용 중인 기기의 브라우저에만 저장되고, 구글을 포함해 어디로도 전송되지 않습니다. [저장 방식 바꾸기]에서 구글 시트에 저장하기를 고른 경우에만 아래 표와 같이 저장됩니다.

정보저장 위치
학급 이름, 학생 번호·이름·역할, 날짜별 수행 기록, 결석, 쉬는 날로그인한 사용자의 구글 드라이브에 만들어지는 스프레드시트
설정 비밀번호 (암호화된 값)위 스프레드시트 파일의 속성
로그인한 구글 계정의 이메일 주소, 마지막으로 연 학급사용 중인 기기의 브라우저 저장소

운영자와 제3자는 위 정보에 접근할 수 없습니다. 광고, 분석, 추적 도구를 사용하지 않습니다.

2. 구글 계정 권한

  • 이 앱으로 만든 구글 드라이브 파일 보기 및 수정 (drive.file): 기록용 스프레드시트를 만들고 읽고 쓰는 데만 사용합니다. 드라이브의 다른 파일은 볼 수 없습니다.
  • 로그인한 계정의 이메일 주소는 위 권한으로 구글 드라이브 계정 정보에서 읽으며, 다시 로그인할 때 같은 계정을 자동으로 고르고 설정 화면에 로그인한 계정을 보여 주는 데만 사용합니다.

구글에서 받은 정보는 위 목적 외에 사용하지 않으며, 다른 곳으로 옮기거나 판매하지 않습니다. 이 앱의 구글 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 보관과 삭제

  • 기록은 사용자의 구글 드라이브에 있으므로, 스프레드시트 파일을 지우면 모두 삭제됩니다.
  • 앱의 설정 화면에서 로그아웃하면 브라우저에 저장된 이메일 주소가 지워집니다.
  • 앱의 권한은 구글 계정의 서드 파티 앱 및 서비스에서 언제든 해제할 수 있습니다.

4. 학생 정보에 관한 안내

학생 이름은 사용하는 교사의 책임 아래 교사의 구글 드라이브에 저장됩니다. 소속 학교와 교육청의 개인정보 처리 기준에 맞게 사용해 주세요. 이름 대신 번호나 별명을 입력해도 앱은 똑같이 동작합니다.

5. 문의
